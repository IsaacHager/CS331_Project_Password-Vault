Password Manager

CS331 security demo — add, log in, or remove an account

Command line equivalent 
java UserLoginUI <add|login|remove> <username> <password>

add    - create a new user
login  - check a user’s credentials
remove - delete a user (requires correct password)
username: letters, numbers, underscore (4–16 chars)
password: letters, numbers, symbols (8–16 chars)
Choose what you want to do.
4–16 characters: letters, numbers, underscore.
8–16 characters; symbols like !@#$%^&*() work too.

Passwords are hashed with PBKDF2-HMAC-SHA256 and a per-user salt before storage.
